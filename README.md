**Fungus** is an immersive, atmospheric **3D First-Person Shooter (FPS)** developed using the **Unity** engine. Survive the nightmare in a singleplayer experience where dynamic combat and tense situations are around every corner.

---

## 🚀 Overview
Fungus was created as a solo development project to master key game mechanics: advanced FPS systems, high-tension atmosphere, and optimized AI behavior.

* **Genre:** FPS / Action / Survival
* **Platform:** PC (Windows)
* **Status:** Released
* **Author:** Sotos Drs
* **Published:** Feb 27, 2024
* **Updated:** Sep 19, 2024

## 🛠️ Tech Stack & Technical Details
* **Game Engine:** Unity (3D)
* **Scripting:** C#
* **Assets:** Custom and selected third-party assets.
* **Optimization:** Designed for stable performance on standard hardware.
